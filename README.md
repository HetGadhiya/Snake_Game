# 🐍 Snake Game in Java (AWT)

This is a classic **Snake Game** implemented using **Java AWT** and **multithreading**.  
The project demonstrates core Java concepts such as graphics rendering, keyboard event handling, arrays, and game loops.

---

## 🎮 Game Features

- Classic snake movement using **arrow keys**
- Randomly generated food
- Snake grows in length after eating food
- Score increases as food is collected
- Game over when:
  - Snake collides with the wall
  - Snake collides with its own body
- Smooth gameplay using a separate game thread

---

## 🛠 Technologies Used

- Java
- AWT (Abstract Window Toolkit)
- Graphics & Event Handling
- Multithreading
- OOP Concepts

---

## 🎯 Controls

- ⬅ **Left Arrow** – Move Left  
- ➡ **Right Arrow** – Move Right  
- ⬆ **Up Arrow** – Move Up  
- ⬇ **Down Arrow** – Move Down  

---

## 📚 Learning Outcomes

- Understanding Java AWT graphics
- Handling keyboard inputs
- Implementing a game loop using threads
- Collision detection logic
- Managing game state and scoring
